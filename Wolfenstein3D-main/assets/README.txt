Place PNG sprites here:
- monster.png        (grunt monster default)
- monster_fast.png   (fast monster variant)
- monster_brute.png  (brute monster variant)
- monster_tank.png   (tank monster variant)
- weapon.png   (used for first-person HUD weapon)
- wall.png     (used for wall columns in raycaster)
- door.png     (used for door columns in raycaster)

Recommended:
- monster*.png with transparent background (around 128x128 or 256x256)
- weapon.png with transparent background (around 512x256)
- wall.png and door.png can be opaque textures (for example 256x256)

The game has procedural fallback rendering if these files are missing.
